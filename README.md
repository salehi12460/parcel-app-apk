# Parcel App Android APK – v12
این پروژه نسخه Android برنامه «مرسولات پستی» بر پایه فایل v12 است.

## ساخت APK بدون نصب Android Studio
1. کل پوشه را در یک GitHub repository قرار دهید.
2. از Actions، workflow با نام Build APK را اجرا کنید.
3. در پایان، Artifact با نام `parcel-app-debug-apk` را دریافت کنید.
4. فایل `app-debug.apk` را روی گوشی نصب کنید.

این نسخه از WebView محلی استفاده می‌کند و امکانات JavaScript، دوربین و انتخاب تصویر از گالری را فعال می‌کند.
